# SQL: 10 задач по базе StreamFlex

Учебные задачи по базе данных видеостримингового сервиса StreamFlex. Диалект: PostgreSQL.

- [streamflex_tasks.pdf](streamflex_tasks.pdf): условия задач и схема базы (дано в курсе).
- [streamflex.sql](streamflex.sql): мои решения, каждая задача отмечена комментарием `task 01` … `task 10`.

## Схема

Схема `sf`, 6 таблиц: `users` (с реферальной связью), `plans`, `subscriptions`, `payments`, `shows`, `viewings`.

## Задачи и приёмы

| № | Задача | Что использовано |
|---|---|---|
| 1 | «Хиты» по странам: шоу с большим временем просмотра и выше среднего по стране | CTE, цепочка JOIN, `DENSE_RANK` |
| 2 | Шоу, которые смотрели платные пользователи и не смотрели полностью бесплатные | `EXISTS`, `EXCEPT` |
| 3 | Страны, где средний платёж выше максимальной цены тарифа | CTE, `CROSS JOIN`, агрегации |
| 4 | Чистая и «грязная» выручка | Сравнение `UNION` и `UNION ALL`, агрегации по платежам и возвратам |
| 5 | Топ устройств по пользователю | `RANK` с `PARTITION BY` |
| 6 | Скользящая 7-дневная выручка по странам | Календарь через `generate_series`, оконная сумма `ROWS BETWEEN 6 PRECEDING AND CURRENT ROW` |
| 7 | Дерево рефералов | `WITH RECURSIVE`, уровень вложенности, путь |
| 8 | Рейтинги по нескольким метрикам в одном результате | CTE, `ROW_NUMBER`, `UNION ALL` |
| 9 | Изменяемое представление для премиальных подписок | `VIEW`, триггеры `INSTEAD OF` на PL/pgSQL |
| 10 | Совокупный retention по когортам | Календарь месяцев, когорты по первому месяцу подписки, агрегации |

## Что полезно проверить при чтении

- В задачах 1, 5 и 8 важно, как ранжирующая функция ведёт себя при равных значениях: `RANK`, `DENSE_RANK` и `ROW_NUMBER` дают разные результаты.
- В задаче 4 `UNION` вместо `UNION ALL` удаляет повторяющиеся суммы платежей и искажает итог.
- В задаче 6 календарь нужен, чтобы окно из 7 строк соответствовало окну из 7 дней при пропусках в данных.
