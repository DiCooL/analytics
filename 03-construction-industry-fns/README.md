# Анализ строительной отрасли (ОКВЭД 41.20) по данным ФНС

Учебное исследование: оценить, как выглядят финансовые результаты компаний в сегменте жилищного и нежилого строительства, по открытым данным налоговой службы.

Ноутбук: [construction_industry_analysis.ipynb](construction_industry_analysis.ipynb)

## Что сделано

1. **Подготовка данных.** Реестр ФНС отфильтрован до компаний отрасли (около 97,6 тыс.), из них случайно выбрано 50 тыс. ИНН.
2. **Сбор отчётности.** Данные бухгалтерской отчётности запрошены через API БФО (bo.nalog.ru). Отчётность получена по 1 308 компаниям.
3. **Показатели.** EBIT, рентабельность EBIT и чистая прибыль за 2021–2025 годы.
4. **Распределения.** Boxplot по годам и распределение темпов роста чистой прибыли за 4-летний горизонт.
5. **География.** Карта финансовых результатов по городам (geopy, geopandas, folium).

Инструменты: pandas, requests, matplotlib, geopy, geopandas, folium.

## Данные

Файл реестра `register.xlsx` в репозиторий не добавлен. Отчётность собирается из открытого API БФО, повторный запуск требует доступа к нему.

## Ограничения

Работа учебная, выводы относятся к выборке из 1 308 компаний (около 2,6% от 50 тыс. запрошенных ИНН), а не ко всей отрасли. Известные недочёты, которые требуют доработки:

- Темпы роста отфильтрованы по модулю 100%, поэтому крайний интервал гистограммы отражает границу фильтра.
- Рост от низкой или отрицательной базы плохо интерпретируется.
- Часть координат на карте определена неточно (геокодинг по названию города).
- Подпись единиц на карте требует проверки: данные в тысячах рублей.
