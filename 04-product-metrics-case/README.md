# Кейс: метрики и юнит-экономика сервиса доставки фермерских продуктов

Учебный кейс по продуктовой аналитике. Решение: [metrics_case.pdf](metrics_case.pdf) (1 страница).

## Что в решении

**Иерархия метрик**
- Бизнес-цель: рост contribution profit (выручка минус переменные расходы).
- North Star Metric: число успешно доставленных заказов активным клиентам. Метрика отражает ценность, которую получает пользователь.
- Декомпозиция: заказы = активные клиенты × частота заказов; средняя стоимость заказа = товаров в корзине × средняя цена. На число клиентов влияют трафик и конверсия, на повторные заказы retention, качество сервиса и удовлетворённость.
- Критичные для фермерского сервиса показатели: доступность товаров, число отменённых заказов, свежесть.

**Юнит-экономика**
- Unit: один успешно доставленный заказ.
- Доход заказа: товары и дополнительные сборы за вычетом скидок и возвратов.
- Переменные расходы: закупка у фермеров, логистика, сборка, упаковка, эквайринг, возвраты, списания.
- На уровне клиента: CAC, среднее число заказов, LTV, LTV/CAC, срок окупаемости CAC.
