# A/B-тесты и статистика

Два ноутбука из курса по аналитике. Первый про основы и дизайн экспериментов, второй про прикладные задачи на данных.

## ab_testing_foundations.ipynb: основы и дизайн экспериментов

Что разобрано:

- Модель конверсии: биномиальное распределение, z-тест для долей, доверительные интервалы. Пример: A/B-тест страницы заявки на банковскую карту (выборки 2574 и 2855 клиентов).
- Расчёт размера выборки и длительности теста: тест баннеров по CTR, средний чек после внедрения рекомендаций, видеоплеер в ленте, ускорение загрузки сайта (метрика bounce rate).
- Аудит сырых данных эксперимента: пользователи, попавшие сразу в несколько групп, полные дубли. После очистки осталось 4821 запись из 10 000, и вывод ноутбука: сначала проверить систему разбиения трафика.
- Выбросы, проверка нормальности, критерий Манна–Уитни. Оценка мощности: около 29%, поэтому отсутствие значимой разницы не доказывает отсутствие эффекта.
- Продуктовая часть: ключевые метрики для выбранного продукта, гипотезы, приоритизация по ICE, шаблон дизайна эксперимента и план теста с защитой от проблемы подглядывания (peeking).

Эксперимент: ворота на 30-м уровне (контроль) против 40-го (тест), 90 189 игроков.

Рекомендация в ноутбуке: оставить ворота на 30-м уровне. Разница в retention 7-го дня составляет −0,8 п.п. (около −4% относительно).
