# Analytics: учебные проекты

Работы курса по аналитике: Python, SQL, метрики и A/B-тесты. Репозиторий собран как портфолио: в каждой папке есть свой README с описанием задач, методов и выводов.

Автор: Леонид Славеснов, прикладная математика (МГТУ им. Н. Э. Баумана), магистратура «Корпоративный отчёт и право в бизнесе» (Финансовый университет при Правительстве РФ).

## Проекты

| Папка | О чём | Инструменты | Что показывает |
|---|---|---|---|
| [01-ab-testing](01-ab-testing) | Два ноутбука по A/B-тестам: основы и дизайн экспериментов, затем 11 прикладных задач, включая разбор теста Cookie Cats | Python: pandas, SciPy, statsmodels, seaborn | Проверку гипотез, расчёт выборки и мощности, работу с «грязными» данными, формулировку выводов для менеджера |
| [02-sql-streamflex](02-sql-streamflex) | 10 SQL-задач по базе стримингового сервиса StreamFlex | PostgreSQL | CTE, оконные функции, рекурсию, представления и триггеры, когортный анализ |
| [03-construction-industry-fns](03-construction-industry-fns) | Финансовый анализ строительной отрасли (ОКВЭД 41.20) по открытым данным ФНС | Python: pandas, requests, matplotlib, geopandas, folium | Сбор данных через API, расчёт EBIT и рентабельности, визуализацию и карту |
| [04-product-metrics-case](04-product-metrics-case) | Дерево метрик и юнит-экономика сервиса доставки фермерских продуктов | Разбор кейса (PDF) | Продуктовое мышление: целевая метрика, декомпозиция, юнит-экономика |

## С чего начать

- Быстрее всего оценить подход к экспериментам: раздел про Cookie Cats в [ab_testing_cases.ipynb](01-ab-testing/ab_testing_cases.ipynb) (последняя задача ноутбука).
- Уровень SQL: [streamflex.sql](02-sql-streamflex/streamflex.sql), условия в [streamflex_tasks.pdf](02-sql-streamflex/streamflex_tasks.pdf).
- Работа с данными от сбора до визуализации: [ноутбук по строительной отрасли](03-construction-industry-fns/construction_industry_analysis.ipynb).

## Важно знать

- Это учебные работы. Часть задач взята из учебных кейсов и открытых датасетов (например, Cookie Cats), поэтому в каждом README указано, что в задаче было дано, а что сделано в решении.
- Исходные данные в репозиторий не добавлены: ноутбуки читают локальные файлы, источники указаны в README папок. Выводы ноутбуков сохранены в самих файлах, поэтому результаты видны без запуска.
